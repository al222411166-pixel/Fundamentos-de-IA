# Fundamentos-de-IA

Prácticas y ejercicios de lógica proposicional, sistemas expertos y conexión a bases de datos.

## Estructura del Proyecto

- **Scips/Ejercicio1.py**: Lógica proposicional para evaluación de alumnos (aprobado / reprobado).
- **Scips/Ejercicio2.py**: Caso de estudio - Autorización para examen con operadores lógicos.
- **Scips/Ejercicio3.py**: Operaciones lógicas detalladas (conjunción, disyunción, condicional, bicondicional).
- **Scips/Ejercicio4.py**: Generador automático de tablas de verdad mediante combinatoria.
- **Scips/Ejercicio5.py**: Sistema de Diagnóstico de Equipos de Cómputo (Consola / Terminal).
- **Scips/Ejercicio6.py**: Sistema Experto de Triaje Médico y Asignación de Citas (Consola / Terminal).
- **Scips/Ejercicio7.py**: Sistema de Diagnóstico de Equipos de Cómputo (Interfaz Gráfica Tkinter).
- **Scips/Ejercicio8.py**: Sistema de Triaje Médico y Asignación de Citas (Interfaz Gráfica Tkinter).
- **Scips/Ejercicio9.py**: Conexión, inserción y verificación de datos en MongoDB Atlas.
